Research

React When You Need To

Event-Triggered Asynchronous Inference for VLA Policies

Yansong Wu, Huaqing Li, Tianding Hou, Lingyun Chen, Alois Knoll

Bachelor’s thesis research · arXiv preprint · 2026

When should a robot update its plan? A pairwise visual trigger compares the current scene with the observation behind the active action chunk, starting inference earlier when the scene changes. Asynchronous execution and action blending help the robot keep moving between updates.
